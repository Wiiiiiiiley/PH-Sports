# PH Sports

PH Sports is a website for sports teams and clubs at Pinghe School. It brings training records, team information and venue bookings together for students, teachers and school administrators.

Students can follow their training and stay updated on their teams. Teachers and coaches can review training records, post announcements and handle booking requests.

## Features

- **Team membership:** Join multiple sports teams, view team members and manage memberships from a student profile.
- **Training records:** Log session dates, duration, notes and sport-specific statistics, such as rowing distance, basketball shooting results or tennis serves.
- **Progress charts:** Review training history through charts tailored to each sport.
- **Monthly leaderboards:** Compare training activity within a team using relevant measures, including distance, sessions completed and frames won.
- **Team announcements:** Read updates from teachers and coaches, with priority labels for important or urgent notices.
- **Venue booking:** Request a venue up to two weeks in advance by selecting a date, time, duration and purpose. Track whether a request is pending, approved or rejected.
- **Teacher and admin tools:** Review teacher registrations, approve booking requests with comments, and manage team members and announcements.

The dashboard shows recent training, team updates and upcoming approved bookings. The layout adapts to desktop and mobile screens.

## Sports

The site includes rowing, basketball, volleyball, football, tennis, table tennis, badminton, ultimate frisbee and billiards.

Each sport has its own training fields and leaderboard measures. Venue booking is available for the listed sports except rowing.

## Built With

The frontend uses React, Vite and Tailwind CSS, with Radix UI components. React Query and Axios handle API requests, while Recharts displays training statistics.

The backend uses Cloudflare Pages Functions and a Cloudflare D1 database.
