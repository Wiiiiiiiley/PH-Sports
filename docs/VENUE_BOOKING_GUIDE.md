# 场地预订功能 - 学生指南

## 功能概述

学生现在可以通过场地预订页面申请预订场地进行队伍训练、个人练习或比赛。所有学生的预订初始状态为 **pending（待批准）** ，需要教师审核后才能最终确认。

## 如何使用

### 1. 访问场地预订页面

- 从菜单栏点击 **"Venue Booking"** 或 **"场地预订"**
- 页面会显示一个 2 周的日期日历，包含所有可用时间段

### 2. 选择预订时间

- 浏览日历找到你想预订的日期和时间
- 点击任何可用的时间槽（灰色区域）
- 已预订的时间槽会显示为彩色块（当前状态用浅色表示待批准）

### 3. 填写预订详情

弹出表单中需要填写以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| **Your Name** | 你的姓名 | 张三 |
| **Team ID** | Team identifier | 2026-04-07-14:22:12-basketball |
| **Venue** | 场地名称 | 体育馆 A、外场 B |
| **Duration** | 预订时长（分钟） | 60（1小时）、90、120 |
| **Purpose** | 预订用途 | 队伍训练、个人练习、比赛 |

### 4. 提交预订申请

- 点击 **"Submit Booking Request"** 按钮
- 系统会显示成功信息：**"Booking request submitted! Your teacher will review it shortly."**
  - 这表示你的申请已提交，等待教师批准

## 预订状态说明

### 学生创建的预订

| 状态 | 含义 | 颜色 | 说明 |
|------|------|------|------|
| **pending** | 待批准 | 浅色（透明） | 你的申请已提交，教师正在审核 |
| **approved** | 已批准 | 标准色 | 教师已批准，你可以使用该时间段 |
| **rejected** | 已拒绝 | - | 教师已拒绝，请选择其他时间 |

### 教师创建的预订

教师直接创建的预订自动显示为 **approved（已批准）** 状态。

## 查看预订详情

- 点击日历上的任何预订（彩色块）
- 弹出窗口会显示预订的完整信息，包括：
  - 预订人姓名
  - 运动类型和场地
  - 日期和时间
  - 当前状态
  - 预订用途

## 常见问题

### Q: 为什么我看不到某些运动类型？

**A:** 你只能预订你所在队伍的运动。请确保：
1. 已加入至少一个队伍
2. 该队伍有关联的场地信息

要加入队伍，请到你的个人资料并使用"Join Team"功能。

### Q: 我的预订申请被拒绝了怎么办？

**A:**
1. 可以选择其他时间段重新申请
2. 联系你的教师了解被拒绝的原因
3. 教师可能在系统中留下批注说明理由

### Q: 预订后可以修改或取消吗？

**A:**
- **待批准状态** ：你可以删除并重新提交
- **已批准状态** ：请联系教师处理修改或取消

### Q: 可以预订多久的时间？

**A:** 
- 最少：30 分钟
- 最多：120 分钟（2 小时）
- 可选择：30min, 60min, 90min, 120min

### Q: 提前多久可以预订？

**A:** 你可以预订接下来 2 周内的场地。

## 技术信息

### API 端点

- **创建预订** ：`POST /api/venue-bookings`
- **查看预订** ：`GET /api/venue-bookings`
- **获取单个预订** ：`GET /api/venue-bookings/{id}`
- **更新预订** ：`PATCH /api/venue-bookings/{id}`
- **删除预订** ：`DELETE /api/venue-bookings/{id}`

### 权限规则

| 操作 | 学生 | 教师 | 管理员 |
|------|------|------|--------|
| 创建预订 | ✅ (需是团队成员) | ✅ | ✅ |
| 初始状态 | pending | approved | approved |
| 批准/拒绝 | ❌ | ✅ (仅限自己教的运动) | ✅ |
| 删除自己的预订 | ✅ | ✅ | ✅ |
| 删除他人预订 | ❌ | ❌ | ✅ |

## 数据库架构

```sql
CREATE TABLE venue_bookings (
    id TEXT PRIMARY KEY,
    booked_by_email TEXT NOT NULL,
    booked_by_name TEXT,
    team_id TEXT NOT NULL,
    sport TEXT NOT NULL,
    venue TEXT NOT NULL,
    date DATE NOT NULL,
    time_slot TEXT NOT NULL,
    duration INTEGER,
    purpose TEXT,
    status TEXT DEFAULT 'pending',  -- 'pending', 'approved', 'rejected'
    teacher_comment TEXT,
    created_at DATETIME,
    updated_at DATETIME
);
```

## 故障排查

### 问题：提交时出现 403 Forbidden 错误

**解决方案** ：
1. 确保你已登录
2. 确保你是选定运动的队伍成员
3. 刷新页面重试
4. 如问题持续，联系管理员

### 问题：日历不显示任何内容

**解决方案** ：
1. 检查网络连接
2. 打开浏览器开发者工具（F12）查看错误
3. 尝试刷新页面
4. 清除浏览器 cookie 并重新登录

### 问题：提交后看不到我的预订

**解决方案** ：
1. 页面可能需要刷新
2. 检查预订是否显示为待批准状态（浅色）
3. 如果仍未显示，稍后再检查
